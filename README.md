# Foco TDAH

Gerenciador de tarefas com temporizador, pensado para pessoas com TDAH.

**Testar:** https://erimenndes.github.io/foco-tdah/

## O que faz
- Fila de tarefas com tempo estimado, uma em foco por vez
- Contagem regressiva com alarme sonoro ao terminar
- Descanso como recompensa: base + tempo economizado
- Compara tempo estimado com tempo real

## Como usar no celular
Abra o link no navegador e use "Adicionar à tela inicial".
As tarefas ficam salvas apenas no aparelho.

## Status
Versão de teste em HTML/JavaScript. Versão final em Python (Streamlit) planejada.
